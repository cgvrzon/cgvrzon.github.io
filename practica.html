Práctica

Proyectos de formación del máster de desarrollo web. Cada uno cierra una técnica concreta y está publicado con su demo y su código: se puede abrir, mirar el marcado y leer por qué está hecho así.

No son proyectos de cliente. Están aquí porque enseñan cómo trabajo cuando el objetivo está acotado: qué mido, qué documento y qué dejo verificado.

Un proyecto, dos entregas

El mismo sitio construido dos veces: primero la estructura, después el diseño. Separarlo obliga a que el HTML se sostenga solo.

Conquer Academy — el sitio con estilos

Sitio de doce vistas para una academia ficticia, maquetado con SASS, mobile first y sin una línea de JavaScript. La paleta no se eligió a ojo: se leyó del CSS de producción del referente, y los roles de cada color salieron de medir contraste.

  • Una sola dirección de interacción, con estado en 169 de 169 elementos interactuables
  • 439 textos verificados de contraste contra el fondo donde caen
  • Entrada por scroll en CSS nativo, sin librerías

SASS · CSS Grid · Flexbox · Imágenes responsive · Accesibilidad

Conquer Academy — la estructura

El mismo sitio, solo con HTML semántico: sin CSS propio, sin JavaScript y sin dependencias. Se ve como se ve un documento sin estilar, y eso es deliberado — el ejercicio era que la información se sostuviera por su estructura.

  • Cero errores y cero avisos en el validador del W3C, en las doce páginas
  • Imágenes responsive con srcset y sizes, sin una línea de CSS

HTML5 · Semántica · Imágenes responsive · SEO
